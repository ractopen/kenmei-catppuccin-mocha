# kenmei-catppuccin-mocha

Catppuccin Mocha Pixel HUD theme for [Kenmei](https://www.kenmei.co) featuring zero border-radius geometry, stepped pixel box-shadows, and retro monospace typography.

## Quick Install

- **Greasy Fork**: [Install on Greasy Fork](https://greasyfork.org/en/scripts/TODO-kenmei-catppuccin-mocha)
- **Direct**: [Install Userscript](https://raw.githubusercontent.com/ractopen/kenmei-catppuccin-mocha/main/kenmei-catppuccin-mocha.user.js)

Requires a userscript manager such as [Violentmonkey](https://violentmonkey.github.io/) or [Tampermonkey](https://www.tampermonkey.net/).

## Highlights

- Full Catppuccin Mocha palette with dark-mode enforcement
- Zero border-radius on cards, inputs, buttons, and popovers
- Retro stepped pixel drop shadows matching Firefox HUD setups
- Monospace typography prioritizing Minecraft and Fira Code

## Development

Source files are split by component under `src/`:

```bash
# Rebuild the root userscript bundle
npm run build
```
